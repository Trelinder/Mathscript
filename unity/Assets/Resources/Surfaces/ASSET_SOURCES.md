# Scanned Surface Sources

These eight 1K JPEG maps are Poly Haven scans, licensed CC0 (public domain).
License verified at https://polyhaven.com/license on 2026-10-10.
No asset scripts, packages, installers, models, or lifecycle hooks were downloaded.

| Local Folder | Source | Maps |
| --- | --- | --- |
| Rock | https://polyhaven.com/a/rock_face | diffuse, OpenGL normal |
| Concrete | https://polyhaven.com/a/concrete_wall_001 | diffuse, OpenGL normal |
| Metal | https://polyhaven.com/a/metal_plate_02 | diffuse, OpenGL normal |
| Bark | https://polyhaven.com/a/bark_brown_01 | diffuse, OpenGL normal |

Download URLs use `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/`
followed by each asset name and its `_diff_1k.jpg` or `_nor_gl_1k.jpg` file.
Every file's MD5 was checked against `https://api.polyhaven.com/files/{asset}`
before import. Unity imports normal maps as linear normal textures and uses
compressed mipmaps, trilinear sampling, and a 1024-pixel maximum size.

Characters, beveled equipment, mine architecture, and branching conifers remain
original project geometry. Scanned surface maps do not make procedural humans
photorealistic.
